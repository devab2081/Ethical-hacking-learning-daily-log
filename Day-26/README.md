What I Learned Today
A structured workflow is key to successful penetration testing.
Reconnaissance is finding subdomains, technologies, and entry points.
Scanning involves automated tools to find common vulnerabilities.
Exploitation is verifying vulnerabilities and demonstrating impact.
Reporting is documenting findings clearly for the client.

Key Takeaways
Don't jump straight to exploitation
Recon is 80% of the work
Document every step
Always get scope authorization
