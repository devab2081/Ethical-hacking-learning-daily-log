What I Learned Today
Logs are the flight recorder of a server.
Web server access logs show who requested what resource.
Attacks often leave patterns in logs (e.g., repeating 404s for scanning, SQLi payloads).
Monitoring tools (SIEM) aggregate logs to find anomalies.
Attackers try to delete logs to cover their tracks.

Key Takeaways
Enable logging on all services
Centralize logs to a secure server
Monitor for repeated failures
Review logs regularly
