What I Learned Today  
Today I learned the difference between client-side and server-side security.  
Client-side security happens in the browser using HTML and JavaScript.  
It can improve user experience but it is not fully secure because attackers can bypass it.  
Server-side security happens on the backend server.  
All important validations must be done on the server to prevent attacks.  
I understood that real security must always be implemented on the server-side.  

Key Takeaways  
Client-side validation can be bypassed  
Server-side validation is mandatory  
Sensitive logic must never be exposed  
Backend security is the foundation of web protection
