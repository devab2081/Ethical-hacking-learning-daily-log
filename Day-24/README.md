What I Learned Today
Security misconfiguration is one of the most common vulnerabilities.
It includes leaving default credentials (admin/admin), enabling debug mode in production, or exposing stack traces.
Detailed error messages can give attackers clues about the backend (e.g., SQL syntax errors).
Regular patching and hardening of the server configuration are essential.

Key Takeaways
Change all default passwords
Disable debug mode in production
Keep software up to date
Disable directory listing
