What I Learned Today
Security should be built-in, not bolted-on.
Least Privilege means giving only strictly necessary permissions.
Defense in Depth means multiple layers of security (WAF + Validation + DB permissions).
Proper error handling prevents information leakage.
Using secure frameworks prevents many common bugs.

Key Takeaways
Security is a developer's responsibility
Don't trust user input
Fail securely (don't crash or reveal info)
Keep it simple (complexity breeds bugs)
