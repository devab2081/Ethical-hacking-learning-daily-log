Tools / Platforms Used

What I Learned Today
Hacking without permission is illegal, regardless of intent.
Ethical hackers must always have written authorization.
GDPR protects user data privacy in Europe (and influences global standards).
Responsible disclosure involves reporting bugs to vendors privately before making them public.
Integrity and confidentiality are core ethical values.

Key Takeaways
Get written permission
Respect privacy
Do no harm
Report vulnerabilities responsibly
